# BUB1B-SAR-ML

Cheminformatics analysis of BUB1B kinase inhibitors using RDKit and Python.

## What this contains
- Drug-likeness profiling (MW, LogP, TPSA, LipE)
- SAR map: LogP vs pIC50
- Tanimoto similarity matrix
- Structure visualisation

## Key finding
BUB1B-02 → BUB1B-03 (NMe₂ → NEtMe): 
Tanimoto = 0.831 but 15× potency gain (activity cliff)

## Tools used
Python · RDKit · Pandas · Matplotlib · Google Colab
